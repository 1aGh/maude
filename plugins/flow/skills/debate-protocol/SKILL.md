# debate-protocol

Follow [host conventions](../../HARNESS.md) for Claude Code or Codex.

Debate only at the configured planning, research or review bookends; execute stays solo and quick uses its escalation tripwire. Read config, capability and protocol before convening a panel. Use native subagents and actual native messaging; without messaging, independent verdicts plus consolidation. Keep blind openings, bounded seats, retrieval grounding and one consolidated user interaction. Never fabricate an independent review or emulate a team with scripts.
