# Clean Artifacts

Follow [host conventions](../HARNESS.md) for Claude Code or Codex.

Remove stale or obsolete files from the project workspace.

## Candidate Directories

### 1. Logs

Check for stale logs older than 30 days:

```bash
find logs/ -name "*.md" -mtime +30 -type f 2>/dev/null
```

### 2. Coverage Artifacts

```bash
find coverage/ -type f 2>/dev/null | head -20
```

Coverage files are regenerated on each test run. Safe to remove if stale.

### 3. Build Artifacts

Look for build output directories that can be regenerated:

```bash
ls -la dist/ .next/ .turbo/ out/ build/ 2>/dev/null
```

### 4. Temporary Files

```bash
find /tmp/ -name "ai-workflow-*" -mtime +7 -type f 2>/dev/null
```

### 5. OS/Editor Artifacts

```bash
find . -name ".DS_Store" -o -name "*.swp" -o -name "*~" | head -20
```

## Never Touch the orbit Spool

`integrations.tracker.artifacts.spoolDir` (default `.ai/tmp/orbit-spool`) is **not** temporary-file territory, whatever its path suggests. Every file there is a plan, RCA, report, retro or review whose push to orbit has not landed yet — deleting one destroys the only copy. Exclude the directory from every scan above and never offer its contents for deletion; the `flow:orbit-backend` resolver sweep is what empties it.

## Review Before Deleting

**Always list files first**, then ask for confirmation:

> **Found X stale files to clean:**
>
> - [list files grouped by category]
>
> **Delete these files?**

## Safe Deletion

Only delete after explicit confirmation. For each category:

1. Log artifacts → `rm` individual files
2. Coverage → `rm -rf coverage/` (regenerated by test)
3. Build outputs → project-specific clean command (`<pm> clean` if available)
4. Temp files → `rm /tmp/ai-workflow-*`
5. OS artifacts → `rm .DS_Store` etc.

## Post-Clean

Report what was cleaned:

```
🧹 Cleaned:
- X log files (Y KB)
- Coverage directory (Z KB)
- X temp files (W KB)
Total recovered: XX KB
```
