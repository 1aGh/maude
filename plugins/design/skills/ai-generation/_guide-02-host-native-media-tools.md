## Host-native media tools

This procedure describes Maude's configured BYOK route. If the host supplies an
image-generation tool and higher-priority instructions require it, follow that
native route and import/localize the resulting artifact before editing the canvas.
Do not silently substitute a provider when the user explicitly selected BYOK;
surface a conflicting host constraint. Model choice for reasoning does not change
Maude's generation provider, key custody, paid-generation gate or asset contract.
