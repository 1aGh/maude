## Verdict

No materially useful simplification patch. The pure address helpers, isolated dialogs, single pending-link slot, and native resolver keep the new behavior reasonably separated. Reformatting the compact JSX or extracting the two visible-file expressions would be stylistic churn, so neither is proposed.

Reviewed the distinctions that must remain intact: shareability versus movability, preview path versus canvas path, one decode at the URL boundary, configured identity before folder fallback, and history traversal without pushing another entry. No blocking correctness finding in those paths.

## Advisory: return-to length contract differs from shareable-path length

The client accepts a decoded file identity of up to 512 UTF-16 code units. The hub accepts a canonical percent-encoded return address of at most 512 characters. Consequently, some links generated by the client open correctly for signed-in users but lose their file target when sign-in is required.

Reproduced directly by importing the existing helpers: `ui/` + `Ž` repeated 90 times + `.tsx` has decoded length 97 and produces a 554-character `/?open=...` address. `buildShareLinks` generates a web link; `validateReturnTo` returns `null`.

This follows the plan's separate limits rather than violating the hub requirement. It is a compatibility limitation to disclose or resolve explicitly, not a safe code-simplification change. Increasing the hub bound blindly is inappropriate: the current cookie encodes the URL again, and sufficiently long Unicode paths can exceed browser cookie limits. A future contract alignment should account for encoded cookie size and add a cross-layer Unicode case.

Proposed patch: none.

## Parent resolution — closeout

The advisory was fixed after this independent review: the hub now validates the same decoded 512-unit identity and stores a canonical bounded UTF-8 base64url cookie. Added Unicode-boundary/forgery tests pass. Both security reviewers re-reviewed the final implementation with PASS verdicts. No simplification patch was applied.
