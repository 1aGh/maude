## Open (named, with why)
- **Canvas re-fit when the AI chat is pinned** (ai-long-pinned): the shell only pumps `occluded-insets`; there is no "fit all" message in the bridge and the canvas does not move its camera when its frame narrows. Needs a `fit-all` dgn (bridge, parent-gated) sent by `app.jsx` when `pinned` / the right slot width changes + the canvas-lib handler (⌘0's `computeFit`) — shared files (dgn-protocol.ts, canvas-lib.tsx), so a patch request.
- **Ghost of the next artboard** ("Mobile — next") in 01 cf-ai-drafting: nothing in the run registry says what the AI will draw next; a ghost would be invented geometry. Needs an agent-side plan frame.
- **Connect sheet "Advanced · Use an API key instead" row**: the API-key option RESTS by guardrail (DDR-123, `ConnectAiSheet.jsx`); drawing a fold with a dead option is a lead decision.
- **Element-level hold rings** in a drafted artboard (hold-rings.tsx, S2.18): a first draft's `objects` are every new element, so Desktop/Tablet show 3 "AI is working" tags each; the board draws none. A filter at the relay (`holdsFor`: draw only objects the run was ASKED about, `scope.elements`) would remove them; it changes the S2.18 conflict signal, so not done here.
- ai-question / ai-permission "Waiting for you" tags on 4 artboards: `ringsFor` only rings the artboards a whole-canvas ask touched (C2 round 2); the re-shot decides whether the fixture still shows 4 (see the stage-D table).
- `ai-attach` thumbnail sliver, `ai-adv-edges` slash menu, suggestion strips, run-list popover, "Always for this canvas" (fake agent offers no `allow_always`), jump pill / resize tooltip / day divider, copy caption + dashed link, a11y A1/A3/A4/A6: not touched this round.
- Per-cause failure verbs ("Pick another clip") need the failing tool's data, which the error does not carry.
