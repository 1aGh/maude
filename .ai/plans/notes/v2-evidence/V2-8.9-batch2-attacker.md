## Exploit chains

The agent runs `sed -i … .design/ui/*.tsx`, and the card looks routine. No window opens, every canvas lands as the person's, the hub publishes at once, and nothing is held for Discard. Severity stays **low**: it needs the card approval, and the hook's Stop gate still checks the files.

The run fails and is held, and Discard reverts the person's edit. Stays **low**: an approved interpreter could overwrite the file directly anyway.

## Tried and held
- **SSRF (import-link):** decimal, octal and hex hosts and `127.1` normalise to `127.0.0.1` and are refused. Also refused: IPv4-mapped, NAT64-embedded, `::127.0.0.1`, `0.0.0.0/8`, CGNAT, 198.18/15, 240/4, fec0::, 6to4, Teredo and ULA. Userinfo and non-443 ports are refused. The connection goes to the checked IP with the hostname in SNI and `Host`, so DNS rebinding has no second lookup to win. Redirects are manual and every hop is re-checked. Proxy env is refused, `decompress:false`, the byte cap is counted while streaming, and idle and total deadlines apply. One import runs at a time and the slot frees only once its DNS lookups settle. The error answer is the same for every unreachable case. The type is sniffed from the bytes and SVG/HTML is refused. Cells refuse it twice (studio `inCell` and hub manifest `REFUSED`). A canvas drag only fills the field.
- **Auto-convert:** a cloned repo's `linkedHub` is parked by link-consent, so `deps.hub()` is null and the engine refuses with `no-sign-in`. Apply needs the person's window. `AUTO_MAX` 3 plus the blocked guard means no loop. Cloud-rc is enforced twice (client hold plus the server's 409 `confirm-cloud`). `config.json` never syncs (`file-membership.ts:281`), so no peer can lower or raise it. A hostile hub can't make the client convert someone else's project.
- **Hub/cell conversion:** both versions must be stable ≥ 2.0.0, and a mistyped kill switch fails closed. The pre-checks run before the backup, so a blocked project gets no backup and no flip. A failed mode switch flips the format back. Backups are pruned within `v2-convert/`, so repeat failures can't grow storage without limit.
- **Collab epoch** keeps honest peers consistent; a hostile peer gains nothing beyond its editor rights. **stamp-follow** is pinned to `activePath`, and its renames come only from server refs. **canvas-origin-probe** is `no-cors`, liveness only.
- **Port binding** is recorded from the app's own info file (loopback only), the preferred port must sit inside the ladder, and the variables are scrubbed from the agent. **parent-watch** shutdown flushes held saves. **paste-forward** goes to the active frame only, on the person's own pick. **object-history-ask** is checked against what the frame has shown. **Held-conflict toast** and **Google key sheet** carry words only (apart from A5). **Index GC** only touches pid-shaped dirs, refuses symlinks and never reaches project data (apart from I2). Trash restore order is just sorting.
