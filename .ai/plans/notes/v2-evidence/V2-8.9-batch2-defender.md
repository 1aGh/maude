## Checked and clean
- **Route table and allowlists:** `CANVAS_SAFE_API` and `routes/canvas-origin.ts` did not change.
  - Every new route is `origin: 'main'`: `/_api/import-link`, `/_api/import-link/key`, `/_api/diagnostics/save-hold-flush`, `/_api/agent/bash/window` and `/_api/agent/write/claim`.
  - The hub manifest refuses all of them. `save-hold-flush` is unlisted, so the default refusal applies.
  - `claimingTableRoute` never wraps a canvas-origin spec or a GET, and it checks `sameOriginWrite` and `isTrustedRequestHost` again.
- **`agent/write/claim`:** paths go through `designPathRel` plus the lane regex, and runtime paths are refused. It takes at most 32 files and 16 MiB, and claims only for a live, non-queued run of that chat.
- **Link import:**
  - https, port 443 only, no name and password in the URL.
  - Every resolved address must be public, with a stricter rule for IPv6. The request goes to the checked address (`Host` and the TLS server name carry the name), so DNS rebinding cannot swap it.
  - Every redirect is checked again, at most 5.
  - `decompress: false`, and a compressed answer is refused. A configured proxy is refused. `rejectUnauthorized` is set explicitly.
  - The byte cap is counted as the body streams, the type comes from the bytes, and SVG is refused.
  - Errors are fixed phrases; private and unreachable sites get the same answer.
  - It needs edit rights on the whole project, refuses canvas-only sessions, and is refused in a cell. One import runs at a time.
- **Cloud and self-hosted conversion (`v2-convert.mjs`):**
  - Both versions must be stable and ≥ 2. A mistyped `CELL_V2_CONVERT` reads as off.
  - Backup first, and a disposable disk is refused. One project's failure never stops the next.
  - A format flip is put back if the save-mode switch fails.
  - `/health` shows only counts and codes, and `by` is regex-limited.
- **Desktop v1 drop:**
  - Projects that still save the old way are view only through `formatGate`.
  - The automatic apply still needs `Sec-Fetch-Site: same-origin`, and a cloud project during the rc needs `confirmCloud`.
  - Only an owner gets past the dry run's role check (`engine.ts:427`), and the token is the local record for that exact hub URL.
  - The migrate steps and the DS folder → canvas conversion are deterministic: no build, no transpile, no repo code runs.
- **Small merges:**
  - **collab epoch:** a regex-checked claim; peers with no claim are read-only and stale peers' frames are dropped.
  - **Parent watch:** it acts only on shell-spawned servers and deletes `MAUDE_EXIT_WITH_PARENT` once read.
  - **Port memory:** `MAUDE_SHELL_PORT` is honoured only inside the ladder, and the port is recorded from the per-spawn info file behind a loopback check.
  - **Index GC:** bearer-only, `PID_RE`, no symlinks, and every candidate is checked before the first delete.
  - **Cell print preflight:** a cell gets no rects runner.
  - **Canvas CSP:** `media-src data:` is media-only. Removing `webrtc` was already a no-op and is documented.
- **Client pieces:**
  - **`stamp-follow`:** it rewrites ids only from server refs, per file and artboard, and a new tree ends the rewrite. A canvas can only cause that reset.
  - **`canvas-origin-probe`:** a `no-cors` GET to `/_health`, with no credentials and no body read.
  - **`paste-data`:** the shell reads the clipboard only on the person's own menu pick. ⌘V fires only with the shell focused, and `run-action` goes shell → canvas, so a canvas cannot trigger it. The payload is typed and size-capped.
  - **`object-history`:** its fields are parsed, and the object must be one the active frame showed.
- **Build and CI:**

  - `cells-deploy` passes repo vars through `env`, not `${{ }}`.
