**Do the shots land under the run dir?** Not under one dir.
- `capture()` writes to `${MAUDE_E2E_RUN_DIR}/native-desktop/step-NN-<label>.png` (`evidence.ts:10,56-57`). If the variable is unset it falls back to `./_e2e-evidence`.
- `v2-gates.mjs` (lines 160-171) never sets `MAUDE_E2E_RUN_DIR`. It only loops `npm run e2e:<lane>`, three runs.
- Each lane config sets the variable itself. `wdio.conf.ts:266` uses `??=`, so a variable set outside survives there. `wdio.remember`, `wdio.video-ai` and `wdio.shell-strip` assign it directly (a `??=` check is only visible for `wdio.conf.ts`).
- So the shots land per lane, under `.ai/device/scenario-runs/<lane-name>/<YYYY-MM-DD-HHMM>/native-desktop/` (for example `video-ai`, `shell-strip`, `remember`, `team-cell`, `team-project`).
- The default `e2e` lane writes to `app-boots-and-renders-canvas/<stamp>/`.
- The gate does not collect them into one folder. The lead will need to read each lane's directory, and a three-run record leaves three stamps per lane.
