## 1. `apps/studio/access/closure.ts` `grantedBySlug` (lines 763–780, used at 789)

**When the new rule can change a result.** It only changes the outcome when two things hold for the stylesheet's same-name owner:
- The owner `.tsx` is not in `env.files` and has no `.meta.json` there.
- `env.isCanvas(owner)` would still have said "canvas". For a file that isn't listed, that can only come from a stored grant (`known`) or a board at the owner's slug.

The `.html` owner is never affected: `isCanvas` needs `files.has(rel)` for `.html` (line 687), and the rule exits early when the file is listed (line 765).

**Bypass paths that hold:**
- **Case folding on macOS.** `canvasSlugFromRel` lowercases (canvas-slug.ts). So the real file that a case-variant owner path opens is always among the files sharing that slug. If it isn't granted, it counts as foreign and the import is refused.
- **Slug twins.** Any `.tsx`/`.html` at the same slug outside the grant marks the slug foreign, even when it isn't a canvas. That matches the `slugTwins` and `ownedOf` fail-closed rule (lines 462–506).
- **A board or grant a member could create.** Adding a board or a file can only add canvas-ness or a foreign twin, so it can only cause more refusals. A member can't widen what a frame reads this way.
- **`_`-prefixed dirs.** `importable` refuses a `_` dep before the owner check. A twin that starts with `_` can't be a case variant of a non-`_` stem.
- **DS surface style.** The path is unchanged; `isDsSurfaceStyle` still gives no owners.
- **A refused canvas's CSS from a sibling frame.** A real file, an exact-path meta, or any listed twin keeps the import refused. The four cases in `apps/studio/test/p8-perf-814-closure-case.test.ts` pin this.
- **Unicode normalisation (NFC/NFD) and case pairs** where JS `toLowerCase` differs from APFS folding (`ς`/`σ`). A board at the owner's slug there is the granted canvas's own board, not the victim's. Without such a board the old code already let the import through, so the delta adds nothing.
- **Cache.** `slugOwned` is created per `walkImports` call, and `granted` doesn't change during a call, so it can't go stale.

**Warnings (Low):**
- **L1 — `closure.ts:765`: "not in `env.files`" is treated as "no file on disk".** `diskProjectReader.list()` (`apps/studio/access/request.ts:521-547`) leaves out symlinked files (`Dirent.isFile()` is false for them) and stops at `LIST_CAP` = 20000.
  - Exploit path: a foreign canvas `ui/b.tsx` exists as a file symlink, or sits past the cap, while `ui/b.css` is a regular, listed file. An attacker editing a granted twin `ui-b.tsx` can now import `./ui/b.css`. Before this change, the board at slug `ui-b` refused that import.
  - This only gives a stylesheet to a frame. It needs a symlinked canvas or a project over 20k files, plus a planted twin. Without the board, the old code already let it through, so this narrows an existing gap rather than opening a new class.
  - Fix: return false when the owner exists on disk even though it isn't listed (`lstat`). Or, more simply, return false whenever the listing was truncated.
- **L2 — `closure.ts:765`: the rule doesn't check stored grants.** A grant held by another subject on an owner path that is now unlisted or deleted no longer refuses the import. Before, `known` made `isCanvas` return true (line 689).
  - Exploit path: a stylesheet left over from a deleted, still-granted canvas becomes readable to a granted slug twin.
  - Fix: start `grantedBySlug` with `if (known.has(owner)) return false`. That needs `known` exposed on `WalkEnv`. Add a red-first case to `p8-perf-814-closure-case.test.ts` (`knownCanvases: ['ui/2026/combine/combine-admin.tsx']`).

**Existing gap, not from this delta (Low):** suppose canvas `ui/B.tsx` has a meta at its own path, no board, and a stylesheet named in a different case, `ui/b.css`. Any frame can import that CSS, because `isCanvas('ui/b.tsx')` is false. Same-name CSS protection is path-exact. This was true before `e308179d0`.

**Consistency note (fails closed, not a vulnerability):** the DS-system pass at `closure.ts:956` doesn't apply `grantedBySlug`. It can refuse more than the import walk does, but never less.
