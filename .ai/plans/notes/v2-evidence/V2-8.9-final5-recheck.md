**New findings:**
- **Low — the hub/cell reader fails open, not closed** (`apps/hub/src/access-files.mjs:153-181`).
  - It implements none of `listTruncated` / `present` / `unlisted`. It also silently stops at 20000 files and depth 8, and skips dot names and symlinks.
  - So the interface comment "a reader without it lists everything it holds" (`closure.ts:213-214`) is false for it.
  - Not reachable through sync: synced names are ASCII with no leading dot, they are regular files, and every journal path is added to `list()` past both caps. So a synced twin is always listed.
  - What's left needs disk-only content in a self-hosted checkout.
  - Fix: implement `listTruncated` there (cap or depth hit), and `unlisted` from the same walk.
- **Low — the two new name checks don't handle Unicode normalization, but APFS does** (`request.ts:539`, `closure.ts:803`).
  - Chain: a git-delivered symlink `café.tsx` in NFD, plus a plain NFC `café.css`, plus a granted NFC `café.html`.
  - `present()`'s exact compare misses the symlink, and the NFD slug in `unlisted` doesn't match the NFC slug. So the stylesheet is imported.
  - Only reachable through a git checkout (sync's `FILE_SEGMENT` is ASCII-only).
  - Fix: compare names with `.normalize('NFC')` on both sides. Never case-fold, or Combine-admin breaks again.
- **Low (availability) — `present()` is uncached** (`closure.ts:790`).
  - It costs four `readdirSync` calls per stylesheet import whose owner is missing. They run before the `slugOwned` cache check and block the event loop.
  - Cost grows with imports × folder size, recomputed on every change to the tree.
  - Reachable by an editor peer through sync (a canvas importing thousands of `.css` files in a large folder).
  - Fix: cache one name set per folder inside `walkEnv`.
- **Info:** `skipped` entries don't count toward the cap, so `unlisted` isn't capped. But the walk is already linear in the number of entries, and sync can't plant dot names.
- **Info, outside this diff and not caused by the fix:** a stored-grant `.html` canvas that is missing from disk is not a canvas to `isCanvas` (it requires `files.has`). So its same-name stylesheet can be imported by any canvas.
