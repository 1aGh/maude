# Wave-B gate: accessibility audit (WCAG 2.1 AA)

Branch `gate-b-a11y` off `feat/maude-v2` @ 0ac68fb3d (studio 1.9.1), release client built from that tree
(`MAUDE_SKIP_RUNTIME_BUILD=1 bun run build.ts --release`, `git status` clean on `dist/` afterwards). Own studios on scratch
fixtures only (throwaway `HOME` / `XDG_CONFIG_HOME` / machine file, `NO_OPEN=1 MAUDE_NO_AUTOBUILD=1
MAUDE_CANVAS_ORIGIN_SPLIT=0`; never this repo's `.design`): the desktop e2e fixture project (10 canvases incl. six video
canvases, seeded comments), a DS project (`seed-ds-review`, with the real Design system canvas written over the seed's
stub), a DS-switch and a DS-library project, an empty project, a project with one blank canvas, a Home server
(`--home`, page secret) and a project wired to the S5 mock ACP agent for the AI chat.
Playwright Chromium 1600x1000, `window.__TAURI__` stub, `prefers-reduced-motion: reduce` (so axe never reads a
mid-transition colour), axe-core (wcag2a/aa, wcag21a/aa, best-practice; `region` off, as in wave A). Dark and light (theme
set through `POST /_api/ui-prefs`, page reloaded). Shell and the canvas iframe are separate documents; artboard
content (`.dc-artboard-body`) is the fixture's own markup and excluded. About 190 scans (each state in dark and light);
screenshots of the ones that carry findings or anchor a surface are kept in `./a11y/<area>/` (JPEG, label-theme.jpg; the
other scans were clean and their images are not kept); keyboard probes (open, Tab x N, Shift+Tab, Esc, where focus lands) for every sheet/dialog.

**Result: 9 blockers (7 source root causes + 2 token/markup pairs), 7 warnings. The gate needs 0 blockers.**

## Blockers (WCAG 2.1 AA)

### B1. 4.1.2 (A): a comment row is `role=button` and holds buttons (axe `nested-interactive`, serious)
- Surface: Comments panel (S9), every thread row, dark and light. Selector `[data-testid=comment-item-<id>]`
  (`div.cmp-row[role=button][tabindex=0]` containing Resolve, the row menu and the where-chip). `a11y/comments/00-comments-panel-*.jpg`.
- Owner: `client/v2/comments/comments-panel.jsx`. Fix: the row is a plain container; the thread opens from a real
  `<button class=cmp-open>` that holds the avatar and the words (a click anywhere on the row still opens it for a pointer).

### B2. 1.4.3: `--accent-text` is undefined in the shell scope; "Uses <system>" reads 2.33:1 (axe `color-contrast`)
- Surface: Inspector with a clip/artboard selected (S10.13 "Uses project" door), dark 2.33:1 (#8e9398 on #3e5495) and light.
  `.insp-uses-link > span`, `span > strong`. `a11y/video/03-clip-selected-*.jpg`.
- Root cause: `--accent-text` (and `--accent-soft`, `--spark-text`, ...) exist only under `.maude-v2[data-theme]`
  (`1-tokens-maude-v2.css`); the shell is `.maude[data-theme]` and never carries `.maude-v2`. 29 shell rules use
  `var(--accent-text)` with no fallback; the declaration is invalid at computed time and the text inherits grey, on the
  shell's heavy `--accent-muted` ground. Shared file: `client/styles/1-tokens-maude.css` (both theme blocks).

### B3. 1.4.3: timeline Advanced buttons wear the browser's grey (`color-contrast`, dark)
- Surface: Timeline island, Advanced fold (S7): "Open in code view" 1.71:1, the unselected Timecode | Frames | EDL | Code
  segments 2.76:1 (foreground on UA `buttonface` #6b6b6b). `.tla-link`, `.tla-seg-btn`. `a11y/video/02-island-clips-dark.jpg`.
- Owner: `client/v2/timeline/advanced/advanced.css` (no `background`/`border` on a `<button>`).

### B4. 1.4.3: a match inside a palette row's meta, 4.24:1 (`color-contrast`, dark)
- Surface: Cmd-K (S12 additions / S2 search), a query that matches a row's meta ("Video" in `Video · ui`).
  `.st-pal-meta > mark.st-pal-mark` (#8e9398 on the accent tint #263047). Wave A's B4 fixed the selected row's meta, not the
  marks inside it. `a11y/palette/q-video-dark.jpg`. Owner: `client/v2/search/search.css`.

### B5. 1.3.1 (A): `role=menu` holds the search input (`aria-required-children`, critical)
- Surface: Export sheet, "Other formats" (S8), dark and light. `[data-testid=export-other-menu]`. `a11y/panels/31-export-other-*.jpg`.
- Owner: `client/v2/export/other-formats.jsx`. Fix: the popover is a plain container (testid kept); only the format rows
  live in `role=menu` (`aria-label`).

### B6. 2.1.1 (A): scrolling regions with no keyboard way in (`scrollable-region-focusable`, serious)
- Diagnostics > Logs (S11): `ol[data-testid=diag-logs-lines]`, dark and light. `a11y/settings/2-diag-logs-*.jpg`.
- AI chat feed (S12/S5): `div.chat-feed`, every AI scan, dark and light. `a11y/ai/00-ai-panel-connected-*.jpg`.
- Fix: `tabIndex=0` (and a name on the feed). Owners: `v2/diagnostics/diagnostics-sheet.jsx`, `panels/ChatPanel.jsx`.

### B7. 1.3.1 (A): the empty project's "New canvas" button is inside `role=tree` (`aria-required-children`, critical)
- Surface: Canvases panel of a project with no canvases (S11 empty states), dark and light. `[data-testid=canvas-list]`
  contains `button[data-testid=canvases-none-new]`: the wave-A B1 class on a path B1's fix did not cover.
  `a11y/empty/00-empty-project-*.jpg`. Owner: `v2/canvases/canvases-panel.jsx` (+ `create/empty-project.css` for placement).

### B8. 1.4.3: the chord on the empty canvas's Ask button, 4.01:1 (`color-contrast`)
- Surface: blank canvas empty state (S11), `.es-keys` ("Cmd /") dimmed by `opacity: .72` on the accent button. Dark and light.
  `a11y/empty/10-blank-canvas-*.jpg`. Owner: `v2/empty/empty.css`.

### B9. 4.1.2 (A): the canvas's Missing frame is `role=img` and holds a button (`nested-interactive`)
- Surface: canvas iframe, a video/picture whose file is missing (S8 relink), dark and light. `.dc-absent[data-testid=asset-frame]`
  with `button[data-testid=asset-frame-relink]`. `a11y/video/10-VideoTranscript-*.jpg`. Owner: `asset-placeholder.tsx`
  (`role=group` when it carries Relink).

## Warnings

W1. Onboarding Advanced sheets (S6: hub, folder/GitHub, AI, CLI, Figma): `<form role=dialog>` is `aria-allowed-role`
(minor); on open focus stays on `body` for four of the five (hub focuses its address field), Tab leaves for the Home page
behind (10 to 12 of 14 presses escape), Esc closes and focus lands on `home-empty-canvas` / `signin-local`, not on the
Advanced button. `aria-modal` without a trap (project hard rule 3). `a11y/home/10-signin-adv-*`. **Fixed with the blockers**
(one fix in `AdvModal`/`AdvSheet`), see the recheck.

W2. No `main` landmark and no `h1` in the shell document when no canvas frame is up (empty project, Home with the
project fallback): axe `landmark-one-main`, `page-has-heading-one` (moderate, best-practice). Also the canvas runtime
document in DS follower and DS-switch states. Wave A listed the shell's missing `main`/`header` as a note; with a frame
mounted axe skips both rules. Not fixed (needs a decision on the shell's landmarks).

W3. Diagnostics opened by a mouse click on a palette row: focus is left on the canvas frame, so Esc does not close it
and Tab stays in the frame (keyboard Enter path is correct: focus enters the sheet, Esc closes, focus returns). The
sheet is non-modal by design (V2-4 gate W3). Pointer-opener class of wave-A W3; not fixed.

W4. Comments panel (docked): Esc does not close it, and after `comments-panel-close` focus falls to `body`
(`comments-panel-close` is the only exit). Same pattern as wave-A W4/W5. Not fixed.

W5. Share sheet role menu (`share-role-menu`): Tab leaves the menu into the sheet's other rows with the menu still open;
Esc closes the sheet and focus lands on `canvas-frame`, not on the person's role button. Menu items are named and arrow
roving works. Not fixed.

W6. Not reachable in this rig, so not scanned: the DS library card (`ds-library-card`, S10.18; the stand-in hub exits
after seeding, the banner appeared once and the card never mounted), the invite landing and the invite sheet (need a
local cell on Node 24 and the Rust shell: covered by `invite-landing.e2e.ts`, which asserts words, not a11y), the live
roles list (scanned against stubbed `/_api/share/*` answers shaped like the unit-test fixtures: owner, member, viewer,
pending invite, request), the Home project rows (the browser-mode Home lists none; empty Home scanned), the DS "Make"
directions (needs a real agent). Settings > Connections sheets other than Advanced doors were not opened.
