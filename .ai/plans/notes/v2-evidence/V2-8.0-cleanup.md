# V2-8.0 Cleanup — part B (old token layers, `.st-*` / `--u-*`, CSS size)

Branch `p8-clean-b`, cut from `feat/maude-v2` @ `f8d62f112`. Part A (dead modules) is merged.

## Method

- **What can style live DOM.** `styles.css` is loaded by `client/index.html` only (canvas iframes and
  comment-mount never load it). So a class can be on an element it reaches only if its name is a token of the
  tree-shaken shell bundle (`dist/client.bundle.js`, release build of the same sources), of `index.html`, or of
  `client/v2/**` source (a v2 component exported but not mounted yet keeps its styles). Dynamic names count:
  a `foo-${x}` / `'foo-' + x` prefix keeps every `foo-*` live, a `${x}-bar` suffix keeps `<token>-bar` live.
  A rule is dead when every selector in its list needs a class that is not live; classes inside `:not()`,
  `:is()`, `:where()`, `:has()` and attribute selectors never kill a selector. Tool:
  `node scripts/v2-css-inventory.mjs` (`--report`, `--names`, `--apply`, `--check`).
- **Why the bundle, not the source.** 63 class names that the inventory calls dead still appear in client
  source — every one sits in an exported-but-unmounted v1 component (`PermissionPrompt` default export,
  `SettingsPanel` `FigmaConnectCard` / `ProviderKeys`, …) or in a comment; the bundle drops them.
- **No visible change.** `scripts/v2-verify/css-ab-rig.mjs` boots the release build on a copy of the desktop e2e
  fixture (+ a Home server; throwaway HOME/XDG, stub `claude`, no cloud), drives each shell state once and
  captures it under stylesheet A and B by swapping the `<link>` in place — same DOM, same moment. It compares the
  computed style of every element of the shell document (+ `::before`/`::after`; hidden-but-mounted panels
  included) and the viewport pixels, A → B → A again (a state only counts when A == A again). Transitions and
  animations frozen for both. A state the rig cannot reach is "not reached", never "identical".
