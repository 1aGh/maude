## Taste decisions (Michal)

- **T1 · What a new canvas is** (D7, D8)
  - a) An empty canvas with the artboard size picker open. Figma and Framer users expect this. **Pick.**
  - b) An empty canvas with one default artboard (Desktop 1440, or the last size used).
  - c) Keep the brief board, rewritten in v2 voice, as the default.
- **T2 · Annotation keys in Edit** (CONTRACT §2 N C M A E S → Preview, Michal 2026-10-08; D1 is what this costs when focus is wrong)
  - a) Keep the jump, but never while a text editor or field has focus, and show "Preview · Sticky — esc to edit". **Pick.**
  - b) Annotation keys do nothing in Edit; only ⌥⌘P or the toolbar switches modes.
  - c) Allow stickies and comments in Edit without a mode switch.
- **T3 · A pointer button in Preview** (D15)
  - a) A V pointer button first in the Preview toolbar. **Pick.**
  - b) Status quo: Hand doubles as the pointer (click selects, drag pans), with a tooltip that says so.
- **T4 · Labelling the mode switch** (D14)
  - a) The words "Edit · Preview" in a segmented control. **Pick.**
  - b) Icons, with a tooltip that carries the key.
  - c) One button that names the mode you'd switch to ("Preview ⌥⌘P").
- **T5 · Left panel when the Inspector opens** (D11)
  - a) Fold it only below about 1280 px. **Pick.**
  - b) Never auto-fold; at narrow widths the Inspector overlays the canvas.
  - c) Status quo, but remember a person's manual unfold.
- **T6 · Comment author on a local project** (D17)
  - a) "You", with the Mac account's initial. **Pick.**
  - b) Ask for a display name on the first comment.
