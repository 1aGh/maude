## Taste decisions

- **T1 · Export in the menus.** The contract has Export… both at root and in File (`11-palette-settings-menus/05-menu-file.png`).
  - (A) Keep both (contract).
  - (B) Root only, and File drops it.
  - (C) File only, with ⇧⌘E.
  - **Pick B.** Root already holds the one-click trio (Version history · Share · Export), and File is 13 rows long.
- **T2 · Trash and Sort, quiet by state** (decision `maude/v2-p8-c5-panel-quiet-by-state`, which overrides CONTRACT §1's "Trash is the last row").
  - (A) Keep it as built: an empty trash lives in Advanced, and Sort hides behind the count.
  - (B) Trash is always the last row (contract C10).
  - (C) Keep A, and show a sort glyph on the count when hovered.
  - **Pick C.** Quiet stays, and Sort becomes findable (`08-left-panel/05-sort-menu.png`).
- **T3 · V in Preview** (`05-preview-vs-edit/06`).
  - (A) V leaves to Edit (now).
  - (B) V selects annotations in Preview (FigJam), and only esc or the mode switch goes to Edit.
  - (C) Preview gets a Select tool button, and V still exits.
  - **Pick B.** V means "select" everywhere, and it unblocks marquee and shift-select of annotations.
- **T4 · Where New artboard lives.**
  - (A) Edit › Advanced (contract).
  - (B) File › New artboard › (Desktop · Laptop · Tablet · Mobile · A4 · Letter · Video).
  - (C) The face of Edit.
  - **Pick B.** It's creation, a peer of New canvas, and the Frame tool's picker already proves the size list.
- **T5 · Artboards in two trees** (IA-11).
  - (A) Keep both.
  - (B) Canvases rows don't expand, and artboards live in Layers only.
  - (C) Keep the expand, but an artboard row there jumps to Layers with the artboard selected.
  - **Pick C.** It keeps cross-canvas jumping and leaves one place for selection.
- **Inspector rules IR-1..17:** no disagreement. IA-10 borrows IR-3 ("the face holds what a designer changes daily; code-facing rows go to Advanced") for menus. Michal could make that a general rule in the skill.
