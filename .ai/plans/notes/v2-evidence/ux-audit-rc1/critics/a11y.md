# a11y-critic: UX audit of Maude 2.0.0-rc.1 (product 20b4215eb)

_2026-10-31 · evidence: `INDEX.md` + `shots/` (25 images read) + source at `lead-merge-2` · standard: WCAG 2.1 AA, plus 2.5.8 (24 px targets, WCAG 2.2) as the target bar for a pointer-first desktop tool_

The axe matrix is clean (`V2-8.7-a11y-final.md`: 318 states, 0 serious). This seat covers what axe can't see: focus order and how visible focus is in the flows, keyboard routes for the new designer things (picker, scrub, clipboard), shortcuts firing while you type, target sizes, and affordances that only show on hover. Contrast ratios are computed from tokens (`1-tokens-maude-v2.css`) and composited the way browsers do it, not measured from pixels. Michal's 20 findings are not repeated here. Where one of mine touches his, it says so.

## On the Inspector rules (only where my lens adds something)

- **IR-8 picker.** Agree. Add: on open, focus goes to Search. Tab out and Esc close it, and focus returns to the chip. Each swatch's accessible name is "<token> — <role>" (not only a hover title). The "selected token is ringed" rule clashes with A5: make selected a check mark or a fill, so the ring means focus. The drawn OKLCH square already has a good 2D `aria-valuetext` (`v2/ds/colour-picker.jsx:94`). Keep it.
- **IR-13 / O4 scrub.** Pick ★a. The handle is a pointer extra and must not become a separate tab stop (two stops per field doubles Tab length). The field stays the keyboard path.
- **O1 density.** Pick ★a (28 px rows). b (24 px) puts every control at exactly the 2.5.8 minimum, with no margin for the hit boxes inside a row.

## Taste decisions

- **T1: what N and C do in Edit** (A2). (a) They switch to Preview and arm the tool, as today, but with an announcement. (b) ★ They arm the tool **inside Edit** (a comment or sticky placed in Edit does not change modes). (c) They do nothing in Edit and a toast says "Stickies and comments live in Preview — ⌥⌘P". Pick b: one key, one meaning, and no surprise mode change.
- **T2: how "selected" looks vs focus** (A5). (a) ★ Selected = filled wash, no ring, so the ring is reserved for focus. (b) Keep the selected ring and make focus a 2px ring with an offset in a second colour (fg-0). (c) Keep both rings and add an underline for selected. Pick a: it matches macOS segmented controls and frees the ring.
- **T3: the tab ×** (A11). (a) ★ Always shown at 40 % on inactive tabs, 24 px hit box. (b) Hover-only as now, but 24 px hit box. (c) No × on inactive tabs at all (⌘W / middle-click only). Pick a.
- **T4: closing Settings** (A14). (a) ★ A visible "Done" in the rail foot (it already exists, so stop hiding it). (b) A × top-right of the sheet. (c) Keep it hidden (Esc / veil). Pick a: no new words, and it removes the hide rule.
