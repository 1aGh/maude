## 1. Scope recap

S8 builds four things:

- **Export (09).** One export sheet. Scope sits on top every time (Selection · This canvas · Folder · Whole
  project, with a computed estimate). The sheet shows the parts each kind needs, and Other… lists every other format.
  Export › Advanced holds exact scale or dpi, colour profile, JPG quality, file-name tokens and the matching command.
  The sheet also handles print preflight (bleed, crop marks, safe-margin and font warnings, the one RGB line), video
  (MP4 · GIF · WebM · Sound only), a past version or "Wait for AI", and cloud vs this Mac.
- **Exports panel and Handoff.** The Exports panel has the last 20 exports, Export again, Retry <name> and "Exported
  114 of 115". Its done toast offers Show in Finder. The inspector gets an Export section, plus Copy as PNG (⇧⌘C).
  Handoff to production (⇧⌘H) gets targets, a ready command and edge cases.
- **Assets (12).** The third tab gets groups with usage, ↵ and drag to place, a wide browse view, By name · Not used,
  details, and Advanced. Search in pictures is opt-in. Drop and paste work, and converters handle PSD, HEIC and PDF.
  A missing file reads either "Waiting for Jonas's Mac" or Missing.
- **Getting things in.** Photo edits apply per use, with "Apply to every use" as a choice. Generate makes N takes and
  ← → switches between them. Figma import brings frames in as exact pictures, with Make editable and FigJam boards
  arriving as annotations. Brand import reads a logo or a website.

## 5. Risks and run order

**Risks**

1. **Lane crossings.** S8.14, and one block each of S8.15 and S8.19, touch canvas-iframe files (L1). They take the L1
   token after S7, or in an L1 idle window. Mitigation: their L1 parts are single blocks listed as patches. The rest of
   each slice lands first behind a feature check, so the shell side is tested on its own.
2. **Hub dependency.** S8.19 needs an L4 slot for `asset-presence.mjs`. If L4 is busy, S8.19 ships a local-only
   rule: a file missing here is Missing in a local project, and Waiting while the project is linked and the hub is
   unreachable. The named "Jonas's Mac" waits for the hub half.
3. **Versioned files.** S8.15 (`data-photo-edit` + per-use files), S8.16 (`.gen.json`) and S8.8 (`artboardMeta.exports`)
   each need the mixed v1/v2 sync test in both directions (memory: test sync in both directions) plus the lead's
   V2-1.12 table rows before merge.
4. **Egress and untrusted input.** S8.17 (Figma), S8.18 (website), S8.20 (describe) and S8.22 (converters) are opus
   slices with security review at merge. Each reuses an existing hardened gate (DDR-216, the fetch-asset gate, V2-1.17
   §5.9, DDR-167) rather than adding a new one.
5. **The bundle.** Every client slice rebuilds `dist/` release-minified. Check `git status apps/studio/dist/` before and
   after each test run (CLAUDE.md).
6. **Size.** S8 is the largest wave-B package: 24 slices, about 2,900 turns. S8.2, S8.10, S8.15 and S8.17 sit at the
   140-turn ceiling. When a builder passes 250k context, it commits and hands back with `## Continue`.
