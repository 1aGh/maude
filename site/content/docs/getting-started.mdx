Three steps: install the app, open a project, make a canvas. Nothing here needs a terminal. If you want the command line, the plugins or a self-hosted hub, they are waiting under [Advanced / Explore Maude](#when-you-want-more) once you have a canvas to play with.

## 1. Install the desktop app

<DownloadNative />

1. **[Download](/desktop)** the installer for your platform — `.dmg` (macOS), `.msi` (Windows) or `.deb` (Linux).
2. Open it. On macOS drag Maude to Applications; on Windows run the installer; on Linux `sudo apt install ./Maude_*.deb`.
3. Start Maude. It opens on **Home**.

Platform requirements, Linux media playback and the first-launch prompt on unsigned builds are on the [Desktop app](/docs/desktop) page. The app keeps itself up to date.

## 2. Open or make a project

Home asks one question: **What shall we make?** A project is the folder of canvases you work in. Pick one way in:

- **Say what to make.** Describe it in a sentence. The chip under the prompt names the project the new canvas lands in. AI puts a first draft on a new canvas.
- **Start with an empty canvas** (<kbd>⌘N</kbd>) — no AI needed.
- **Open project…** (<kbd>⌘O</kbd>) — any folder works. Recent projects and recent canvases sit under the prompt.
- **Sign in to cloud.maude.sh** to keep the project in the cloud: every Mac you use, and everyone you invite, sees the same canvases. A local project works right now and moves to the cloud any time (Share › Move to cloud…). The [cloud trial](/docs/cloud/pricing) is 14 days with no card.

A local project is kept in your Maude folder on this Mac. The folder path is under **Advanced** when you ask for it — never in your way.

<Callout type="info" title="AI uses your own Claude account">
The first time you use **Ask AI**, one sheet asks you to **Connect** your Claude account (Pro or Max, or an API key). Your prompt waits and runs as soon as it is connected. Without a connection every other part of Maude still works.
</Callout>

## 3. Make your first canvas

A new canvas opens with one line in the middle: *Your canvas is ready. Ask AI for a first draft, or start drawing.*

- **Ask AI.** Type what you want and press <kbd>↵</kbd>. The draft arrives piece by piece — artboards land with a small "Made by AI" mark. The AI chat panel keeps what was said.
- **Or draw.** The **Edit** toolbar at the bottom has Select (<kbd>V</kbd>), Hand (<kbd>H</kbd>), Frame (<kbd>F</kbd>), Shape (<kbd>R</kbd>), Pen (<kbd>P</kbd>), Text (<kbd>T</kbd>), Image (<kbd>I</kbd>) and More. Press <kbd>F</kbd> and drag to make an artboard.
- **Change it.** Select anything and the Inspector comes with the selection. With it selected, press <kbd>⌘/</kbd> to ask AI to change just that.
- **Take it back.** <kbd>⌘Z</kbd> undoes AI's changes like any other — one AI run is one undo step. **Version history** (<kbd>⌥⌘H</kbd>) lists every saved version with Restore.
- **Look around.** <kbd>⌘K</kbd> searches canvases, actions and AI; every result says where the thing lives. <kbd>?</kbd> lists all shortcuts.

That is the whole loop. [Around the window](/docs/desktop/window) names each piece you just used, with the exact words the app uses.

## Share it

Press **Share…** (top right). **Invite** people by email, or **Copy link** in the link row. People you invite open the project in their own Maude, or in a browser if they only need to look. See [Share links](/docs/share-links) and [Maude Cloud](/docs/cloud/pricing).
