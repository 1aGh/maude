Maude's window has a handful of pieces and each one has a single job. This page uses the same words the app does, so what you read here is what you can search for with <kbd>⌘K</kbd>.

## The project pill and its one menu

The **project pill** (mark and project name, top left) opens the **Project menu**. It is the only menu inside the window. In this documentation a path through it is written **Menu › File › Export…**.

| Entry | What it holds |
| ----- | ------------- |
| **Back to Home** | Leaves the project for Home. |
| **File ›** | New canvas <kbd>⌘N</kbd>, New project… <kbd>⇧⌘N</kbd>, Open project… <kbd>⌘O</kbd>, Duplicate · Rename · Move to…, Import from Figma…, Import a brand…, Export… <kbd>⇧⌘E</kbd>, Handoff to production <kbd>⇧⌘H</kbd>, Close canvas, Switch account…. |
| **Edit ›** | Undo <kbd>⌘Z</kbd>, Redo <kbd>⇧⌘Z</kbd>, **Undo history…**, cut / copy / paste, Select all. |
| **View ›** | Hide panels / Show panels <kbd>⌘\\</kbd>, Layers, Inspector <kbd>⇧⌘I</kbd>, Comments <kbd>⇧⌘M</kbd>, Assets, Exports, AI chat <kbd>⌘/</kbd>, Annotations, Present, zoom. **Advanced** holds Layers as a panel, Keep timeline open, Minimap, Print guides, Hidden files. |
| **Help ›** | Keyboard shortcuts <kbd>?</kbd>, Help and guides <kbd>F1</kbd>, What's new, Take the tour, Set up Maude…, How sharing works, Report a bug…. |
| **Version history** | <kbd>⌥⌘H</kbd>. Top level, one click. |
| **Share…** | Opens the Share sheet. |
| **Export…** | <kbd>⇧⌘E</kbd>. |
| **Diagnostics ›** | See [below](#diagnostics). |
| **Settings…** | <kbd>⌘,</kbd>. See [below](#settings). |

The Mac's own menu bar is still there, kept short: **Maude** (About · Check for Updates… · Quit), **File** (New canvas, New project…, Open project…, New Home tab), **Edit**, **Window** (the tab commands) and **Help › Report a Bug…**.

## Project tabs

Maude has its own tab strip. **Home** is a pinned, icon-only first tab (<kbd>⌘T</kbd> opens a new one); every project gets one tab, with its square, its name and one small state mark — AI working, done, or needs you. <kbd>⌘1</kbd>–<kbd>⌘8</kbd> jump to a tab, <kbd>⌘9</kbd> to the last. Right-click a tab for its menu.

## Search

<kbd>⌘K</kbd> is **Search**: canvases (by name and by the artboards inside them), pictures, actions, and every tool that is not on screen. Each action result names where it lives — *Menu › File › Export…* — so you learn the menu by using it. **Ask AI** is always the last row. Accents do not matter: `letak` finds *leták*.

## The Share cluster

Top right, one island:

- **Faces** of the people on the project, and next to them **one word** for the save state: *Saved* · *Syncing…* · *Offline — kept on this Mac* · *Local project*. A write that failed and is not queued shows *Not saved* with one action, **Retry**. It is a word, not a control.
- The **Edit · Preview · Present** switch. People who can only look see *Viewing* instead of Edit.
- **Share…** — the Share sheet. **Invite** is the primary button, **Copy link** sits in the link row, and a local project's **Move to Maude Cloud…** lives inside it. See [Share links](/docs/share-links).
- An **Exports** icon with a progress ring appears once any export exists.

## Panels

Panels float over the canvas. <kbd>⌘\\</kbd> hides them all; *Panels hidden. Press ⌘\\ to bring them back.*

- **Left panel** — three tabs: **Canvases · Layers · Assets**. Your project's **Design system** is pinned above the canvases, and **Trash** is the last row of Canvases. A canvas row's **⋯** menu has Open · Pin · Rename · Duplicate · Move to… · Copy link · **Copy relative path** · Move to trash; a menu closes when you click anywhere outside it, not only on <kbd>esc</kbd>. Things you remove are *moved to the trash*, not deleted; only a project owner clears it out.
- **AI chat panel** (right) — a normal conversation. <kbd>⌘/</kbd> is **Ask AI** with your selection attached. AI's changes show live in Preview; one AI run is one undo step.
- **Comments** (right, <kbd>⇧⌘M</kbd>) — filters Open · Mine · Resolved · All. A comment's trash icon deletes it on a second press.
- **Light | Dark** — every canvas has one small pill at the top, in the same place the Design system canvas has it. It switches every artboard on the canvas at once; the design system sets which one a canvas starts in, so there is no per-artboard theme and no "follow the app" setting. The pill also shows the canvas's path inside the project — click it to copy. The switch is two icons, a sun and a moon; if a canvas has no Dark version, the moon is greyed and its tooltip says so.
- **Design system** — a project without one shows an empty view with **Create a design system**, which opens the AI chat with the set-up prompt. A system that is below the schema shows **Bring it up to the schema** in a small card in the corner of the window: it says why the schema matters, and while AI works only that system is locked — the rest of the project stays open.
- **Inspector** — comes with the selection. Closed, its **› Advanced** fold says "Code, tokens, CSS"; open, it adds the element, the tokens bound and the raw CSS rows. There is no separate "words" setting any more: the frame speaks designer, the fold is the code. Panels remember which of their **› Advanced** folds you opened. A colour opens Figma's picker: **Custom** (the area, hue and opacity bars, eyedropper, Hex / RGB / HSL, and the colours **On this page**) or **Libraries** (the design system's colours as a list of named rows). On a fill, **Solid · Gradient · Image** says what the fill is; a gradient's stops drag along the bar, and **Image** takes a file, a link or a picture from **Assets**. Switching between tabs keeps the picker open. Drag a number's label to change the number; selecting text is switched off while you drag.

## Toolbars

The bottom **toolbar** changes with the mode:

- **Edit** — tools that make things inside artboards: Select <kbd>V</kbd> · Hand <kbd>H</kbd> · Artboard / Frame <kbd>F</kbd> · Shape <kbd>R</kbd> · Pen <kbd>P</kbd> · Text <kbd>T</kbd> · Image <kbd>I</kbd> · Component <kbd>⇧I</kbd> · More. Drag a picture or a video from **Assets**, or a file from Finder, onto an artboard or frame to place it. A placed video shows a play button when you hover or select it (<kbd>Space</kbd> plays it too). Right-click an object for its menu: **Ask AI about it** and **Add comment** come first; the code-level rows (Inspect, Copy CSS, Convert children to absolute position…) are under **Advanced**.
- **Preview** — annotation tools only: Hand · Sticky <kbd>N</kbd> · Comment <kbd>C</kbd> · Marker <kbd>M</kbd> · Arrow <kbd>A</kbd> · Shape · Text · Stickers <kbd>E</kbd> · Section <kbd>S</kbd>. The design is live, not editable. Switching to Preview changes only the toolbar: the Canvases and AI chat panels stay where you left them (<kbd>⌘\\</kbd> hides every panel). Click a link in the design and the other canvas opens in Preview, with a **Previewing** bar at the top that takes you back; the bar shows only while there is somewhere to go back to. Pressing an annotation key in Edit switches to Preview with that tool; <kbd>esc</kbd> puts the tool away and clears the selection, but never leaves Preview — <kbd>⌥⌘P</kbd> (or the mode switch) takes you back to Edit. Drag a picture, a video or a file from Assets or Finder onto the canvas and it becomes an annotation. A sticker shows its picture as soon as you pick it, and a stamp can be selected, moved and deleted like a sticker. The **Blank section** tile arms the Section tool: drag to size the section (a click makes the default size), and the tool goes back to Select when you let go. An object you drag into a section moves with it afterwards. Only a drag puts an object into a section: Fan out, align, distribute and the arrow keys never do, even when the object ends up over one. A placed video has a play button in Preview as well. A sticky can be a **checklist**: select a sticky and choose **Turn into checklist** (the sticky's small toolbar, its menu or <kbd>⌘K</kbd>), and its `☐` / `- [ ]` lines become entries under the sticky's title. Click a box, or focus an entry and press <kbd>Space</kbd>, to tick it; <kbd>↑</kbd> / <kbd>↓</kbd> move between entries, <kbd>↵</kbd> in an entry starts the next one, <kbd>⌫</kbd> in an empty entry removes it, and <kbd>⌥⌘↑</kbd> / <kbd>⌥⌘↓</kbd> move it. A "3/5" chip counts what is done, and every tick is one <kbd>⌘Z</kbd>. Ticking needs Can edit; with Can comment or Can view the list is drawn but not clickable. Claude can write and tick entries too (`maude design annotate`), and a tick Claude made wears its spark. A list taller than its sticky can grow shows "+N more".

<kbd>?</kbd> opens the sheet with every shortcut once. If single keys get in the way of typing in another app, **Settings › General › Keyboard** turns them off.

## Version history and undo

**Version history** (<kbd>⌥⌘H</kbd>) lists saved versions of the project — who made each one and when — with a preview and **Restore**. <kbd>⌘Z</kbd> and <kbd>⇧⌘Z</kbd> undo and redo, AI's changes included; **Menu › Edit › Undo history…** lists your steps and AI's.

## Diagnostics

**Menu › Diagnostics** is a submenu for when something is actually wrong, never its own window. It shows a status word for **Sync**, **Server** and **AI setup**, and holds **Logs**, **Reload canvas** (<kbd>⌘R</kbd>) and **Check AI setup again**. Its **Advanced** part holds the address, the process, the project folder, **Resync now** and **Download all**. **Report a bug…** lives in Help.

## Settings

**Menu › Settings…** (<kbd>⌘,</kbd>) has three tabs:

- **General** — your account (every account on this Mac; each project tab is bound to one), Theme (Light · Dark · Auto), canvas and view switches, Keyboard, search in pictures, panel layout.
- **Connections** — Maude Cloud, a self-hosted [hub](/docs/hub), GitHub.
- **Advanced** — the local server port (display only), Decision memory, **Check for updates**.

## Callouts and toasts

Maude does not stack bars across the window. A state that needs you — offline, a sign-in that expired, a canvas that cannot be drawn right now — shows as a **callout** or a toast with one action at most, and it says what happened, what is safe, and one verb. When your work is safe offline it says so: *Offline — kept on this Mac*.
